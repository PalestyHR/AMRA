Instructions

Follow these steps to screen and review records.

  1. Configure the model

    Open Model settings and enter your API key.

  2. Add records

    Leave a blank line between entries. Use ID | and include related history in date order.

  3. Review the findings

    Select Analyze records. Open Source & evidence, check the findings and add your notes.

  4. Export the review

    Export saves the records, model output and your review notes together.

The scoring rule

S = 2e + 2r + 2u + 2c + a

e: symptom · r: recurrence · u: unresolved or deferred · c: critical impact · a: ambiguity · m: missing information.

S ≥ 4 or m = 1 → REVIEW. Other readable entries → ROUTINE. Unreadable entries go to source recovery; output issues → CHECK OUTPUT.
